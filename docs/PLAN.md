# 설문 집계기 계획서

## 목표
엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표를 보여 주는 `index.html` 한 장짜리 도구.

## 제약
- 파일 하나(`index.html`)로 동작한다. 외부 라이브러리·외부 글꼴·분석 도구를 쓰지 않는다.
- 붙여넣은 데이터는 브라우저 밖으로 보내지 않고 어디에도 저장하지 않는다.
  - `localStorage`·`sessionStorage`·쿠키·IndexedDB·`fetch`·`XMLHttpRequest`를 쓰지 않는다.
  - CSP 메타 태그(`default-src 'none'`)로 외부 요청 자체를 막는다.
  - 입력란은 `autocomplete="off"`, `spellcheck="false"`.
- 저장소 맨 위에 빈 `.nojekyll` 파일을 둔다(GitHub Pages가 그대로 배포하도록).

## 집계 규칙
1. 첫 줄은 머리글. 첫 열(응답번호)은 집계하지 않는다. 둘째 열부터가 문항이다.
2. 칸 판정 — 앞뒤 공백을 지운 값이
   - `1`·`2`·`3`·`4`·`5` 중 하나면 **유효**
   - 비었으면(원래 비었거나 공백만 있었으면) **빈 응답**
   - 그 밖의 값(`6`, `0`, `3.0`, `１`, `a` 등)은 **제외**
3. 결과 표 열: 문항 / 유효 응답 / 평균 / 빈 응답 / 제외
4. 평균 = 유효 응답의 합 ÷ 유효 응답 수, 소수 셋째 자리에서 반올림해 둘째 자리까지(예: `3.00`, `2.67`). 유효가 0이면 `-`.
   - 부동소수 오차를 피하려고 정수 연산으로 반올림한다: `round = floor((200·합 + 수) / (2·수))` → 백분의 일 단위 정수.
5. 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 센다.

## 규칙이 정하지 않은 경우의 처리(결정 사항)
- 줄 구분은 `\r\n`·`\n`·`\r` 모두 허용, 칸 구분은 탭(엑셀 복사 형식).
- 엑셀이 따옴표로 감싸 내보내는 칸(칸 안에 줄바꿈·탭·따옴표가 있을 때)을 해석한다. `""`는 `"` 하나.
- 모든 칸이 비었거나 공백뿐인 줄(맨 끝 줄바꿈, 빈 행 포함)은 응답 줄로 치지 않는다.
- 칸 수가 머리글보다 많은 줄의 넘치는 칸은 무시한다.
- 문항 이름은 앞뒤 공백을 지워 쓰고, 비었으면 `(N열)`로 표시한다.
- 머리글만 있고 문항 열이 없거나 입력이 비면 안내 문구를 보여 준다.

## 구조
- `index.html`
  - `<script id="tally-core">`: 화면과 무관한 순수 계산 로직. `SurveyTally` 객체로 `parseTSV`, `classifyCell`, `formatAverage`, `tally`를 내보낸다. DOM을 건드리지 않는다.
  - 두 번째 `<script>`: 화면 연결(입력 → `tally` → 표 그리기). 사용자 값은 `textContent`로만 넣는다.
- `tests/`: Node 내장 시험 도구(`node --test`). `index.html`에서 `tally-core` 스크립트를 꺼내 `vm`에서 실행해 시험하므로 화면 코드와 분리된 로직을 그대로 검증한다. 외부 의존성 없음.
- `.github/workflows/test.yml`: 푸시·PR마다 `npm test`.

## 작업 순서(작업마다 커밋)
1. 계획서
2. `.nojekyll`, `package.json`, 시험 실행 뼈대
3. 계산 로직 + 단위 시험
4. 화면(입력·표) + 페이지 제약 시험(외부 참조·저장 API 없음)
5. CI, README
6. 시험 통과 확인 후 PR
