# 10×10 오목

두 사람이 한 화면에서 번갈아 두는 오목입니다. `index.html`을 브라우저로 열면 바로 할 수 있고, 인터넷 연결도 설치도 필요 없습니다.

## 규칙
- 10줄 × 10줄 판, 흑이 먼저 둡니다.
- 가로·세로·대각선으로 같은 색 돌을 다섯 개 이상 이으면 이깁니다(여섯 개 이상도 승리).
- 판이 다 찰 때까지 승부가 나지 않으면 무승부입니다.
- **무르기**는 마지막 수를 하나씩 되돌리고, **새 게임**은 판을 비웁니다.

## 시험
Node 22 이상, 설치할 것 없음.

```bash
npm test
```
