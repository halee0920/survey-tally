# survey-tally

엑셀에서 붙여넣은 설문 응답을 문항별로 집계하는 한 장짜리 페이지(`index.html`).

- 외부 라이브러리·외부 글꼴·분석 도구 없음. 붙여넣은 데이터는 브라우저 밖으로 나가지 않고 저장되지 않습니다.
- 사용법: `index.html`을 브라우저로 열고, 엑셀에서 머리글 줄까지 복사해 붙여넣습니다.
- 결과 표: 문항 / 유효 응답 / 평균 / 빈 응답 / 제외. 규칙은 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 시험

Node 22 이상, 설치할 것 없음.

```bash
npm test
```

계산 로직은 `index.html`의 `<script id="tally-core">` 블록에 화면 코드와 분리되어 있고, 시험은 이 블록만 꺼내 실행합니다.
